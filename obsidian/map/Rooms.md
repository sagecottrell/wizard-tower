

each room can produce and consume resources

each room and produce and require workers

workers can simulteneously work in a room and deliver outputs to other rooms

workers must be told where to deliver resources.
- configure a set of rooms to deliver a set of resources
- worker configuration can be copied to other rooms
- rooms can be copy-pasted without opening the build menu
- when copying settings/rooms, this is a "link" between the rooms and will be remembered when settings are changed on any of the linked rooms in the future
- user will be asked to update all linked rooms. if no, ask the user if they should be unlinked.
